# CHATBOT_ACTIVATION

## Purpose

Wire all scaffolded chatbot subsystems into functional end-to-end pipelines: persona prompt injection, memory system, identity drift, rooms architecture with behavioral modes and roleplay scenes, avatar generation with companion info panel, and migration consolidation. Transform the chatbot from a demo with hardcoded defaults into a production companion platform where companion personality, memory, mood, and room context all shape every LLM response.
