# CHATBOT

## Purpose

Group 2 of the companion buildout, run after Group 1 (phases i, j, k) is accepted. This group makes the companion's identity user-shapable and its memory trustworthy and continuous. Phase L adds relationship configuration (relationship type, tone, directness, warmth, initiative level, and content level as a configurable runtime setting), character creation/customization (name, backstory, personality sliders feeding the soul core, humor style, favorite topics), and slow controlled identity evolution that distinguishes fixed identity, slowly-changing identity, and temporary mood so the companion grows familiar over time without random drift. Phase M makes memory controllable and transparent: a memory control API (view, pin, delete, edit, mark private/temporary/permanent, do-not-remember, remember-forever, correct-a-misunderstanding), explainable memory with provenance (explicit vs inferred, source turn, confidence), searchable conversation history with date/topic filtering and export, and per-memory privacy levels. Phase N adds continuity and narrative: a relationship timeline of milestones, emotional events, promises, and running projects; a narrative threading engine that produces grounded callbacks beyond naive top-k retrieval; and rituals and shared routines including named recurring activities and inside jokes. All new logic lands inside the existing chatbot package and the react_ui frontend; the FastAPI + Postgres/pgvector + Redis stack is unchanged.
