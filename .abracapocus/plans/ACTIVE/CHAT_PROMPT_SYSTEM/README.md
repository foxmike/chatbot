# CHATBOT_PROMPT_SYSTEM

## Purpose

Wire up memory infrastructure (embeddings, retrieval, background worker, structured logger), then build a modular prompt assembly system with deterministic layer ordering, per-model formatting, intent classification, dynamic token budgeting, companion personality enhancement, mode-aware routing, and prompt observability telemetry. Transforms the current monolithic PersonaPromptAssembler into a layered, model-aware, scene-adaptive prompt engine while preserving all existing chat pipeline behavior.
